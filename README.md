# 숙소 후기 도우미

[Windows 최신 설치 파일 다운로드](https://github.com/seon0030-bot/stay-review-assistant-updates/releases/download/updates/StayReviewAssistant-Windows-v0.6.2.zip)

ZIP 압축을 모두 풀고 `StayReviewAssistant.exe`를 실행하세요. 프로그램에서 에어비앤비에 연결한 후 대상과 문구를 확인해 사용합니다.

## 자동 업데이트

프로그램은 시작할 때와 실행 중 5분마다 최신 버전을 확인합니다. 새 버전이 있으면 알림을 표시하고 자동 작업을 중단합니다. 다운로드와 검증을 거친 뒤 프로그램을 교체하고 다시 시작합니다. 업데이트가 끝나야 작업을 다시 시작할 수 있습니다.

로그인 정보, 설정과 처리 이력은 업데이트 때 유지됩니다. 인터넷 연결에 문제가 있거나 업데이트 확인에 실패하면 자동 작업을 중지합니다. 연결이 복구되면 프로그램에서 업데이트 확인을 다시 실행하세요.

업데이트 기능이 없던 v0.5.3 이하 및 서버 미연결 개발용 v0.6.0은 최초 1회 위 설치 파일로 교체해야 합니다.

## 배포 채널 운영

이 저장소는 배포 파일과 공개 업데이트 운영 코드만 보관합니다. 프로그램 개발 원문이나 사용자 운영 자료는 포함하지 않습니다.

`channel/latest.json`은 RSA-SHA256으로 서명된 최신 버전 정보입니다. 프로그램에 고정된 공개키로 서명과 다운로드 파일의 SHA-256을 검증합니다. 서명키는 GitHub Actions의 암호화된 저장소 비밀값으로 관리합니다.

매일 한국 시간 03:23에 서버가 배포 파일을 다시 검증하고 정보의 유효기간을 갱신합니다. 이 갱신은 사용자의 PC가 꺼져 있어도 실행됩니다. 새 프로그램이 없는 날에는 프로그램을 재설치하지 않습니다. GitHub의 작업 지연·장애가 있을 수 있어 유효기간은 30일로 둡니다. 실패 내역은 Actions 탭에서 확인할 수 있습니다.

새 버전 배포 순서는 버전별 ZIP 업로드 → 다운로드 검증 → 서명된 최신 정보 교체입니다. 이전 버전 ZIP은 진행 중인 다운로드를 위해 유지합니다. 새 버전은 반드시 이전 버전보다 높은 번호를 사용합니다.
